# 5. Read your first run

A QAForge `test_run` carries everything you need to act:

* failure classifications with confidence + reasoning
* the release-risk score with top drivers + go/no-go
* per-test flakiness signals
* cost + latency for the run
* full audit trail (HMAC-signed)

## Anatomy of the PR comment

```markdown
## QAForge AI run #<id>

**Risk:** medium (53 / 100) — go_with_approval
**Top drivers:** fail_rate (0.18) · uncovered_acceptance (0.15) · recent_incidents (0.10)

**Tests:** 87 / 92 passed · 5 failures classified
- 3 product_defect (confidence ≥ 0.80)
- 1 flaky_test (14d flip-rate 0.42)
- 1 environment_issue (DNS lookup failed)

**Cost:** $0.42 of $5.00 budget · **Runtime:** 3m12s of 30m

[View evidence report](https://api.qaforge.ai/api/v1/test-runs/<id>/report)
```

## Decoding the risk score

| Band | Score | Recommendation |
|---|---|---|
| low | 0-30 | go |
| medium | 31-60 | go_with_approval |
| high | 61-80 | no_go |
| critical | 81-100 | no_go |

The 10 drivers (PRD §9.9) come from real signals — fail rate,
critical failures, uncovered acceptance criteria, change volume,
historical defect density, recent incidents, ownership gap, security
sensitivity, untested high-risk modules, flakiness. The top three
in the comment are ranked by `weight × raw` contribution.

## Drilling into a failure

```bash
curl https://api.qaforge.ai/api/v1/test-runs/$RUN_ID/failures \
  -H "Authorization: Bearer $QAFORGE_TOKEN" \
  -H "X-QAForge-Tenant-Id: $QAFORGE_TENANT_ID"
```

Each failure carries:

* `category` — see PRD §9.8 for the canonical set.
* `confidence` — 0..1 (the heuristic + LLM combined classifier).
* `reasoning` + `suggested_fix` — human-readable, generated by the
  agent.
* `signal_id` — links the failure back to the originating test +
  evidence artifact.

## Flakiness check

If a failure looks suspicious, pull its rolling flakiness over 14 /
30 / 90 days:

```bash
curl https://api.qaforge.ai/api/v1/workspaces/$WORKSPACE_ID/flakiness/$TEST_ID \
  -H "Authorization: Bearer $QAFORGE_TOKEN" \
  -H "X-QAForge-Tenant-Id: $QAFORGE_TENANT_ID"
```

A 14-day flip-rate ≥ 0.30 means the classifier already preferred
`flaky_test` over `product_defect` (Story 3.3.2 false-positive
reduction). Investigate the test, don't open a defect yet.
